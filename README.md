# Pong Game

### Description
The classic pong game made with Go, using Raylib.

### Purpose
This project was built with the goal of learning Raylib using a language I'm already familiar with.

### How to Play
You can clone the repository, and run it, or build it yourself:
```
go run .
```

```
go  build -o ./pong.exe .
```
